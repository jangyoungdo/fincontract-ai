FinContract AI 심사용 실험 데이터 v1

이 압축 파일에는 FinContract AI의 계약 검토 흐름을 확인할 수 있는 PDF 11개가 들어 있습니다.
모든 문서는 성능 검증을 위해 제작된 완전한 가상 문서이며, 실제 금융회사·상품·고객과 무관합니다.
실제 계약 체결, 금융거래, 법률 자문 또는 법률 판단에 사용할 수 없습니다.

빠른 체험 방법
1. 01번 PDF를 FinContract AI의 계약서 업로드 영역에서 선택합니다.
2. "분석 시작"을 누르고 분석이 완료될 때까지 기다립니다.
3. 결정론적 검토 신호, 추가 의미 검토 후보와 마스킹된 원문 근거를 확인합니다.
4. 필요하면 PDF 리포트를 내려받고, 확인 후 "원문·결과 삭제"를 누릅니다.

문서별 용도
- 01~09: 여러 위험 표현에 대한 규칙·의미 검토 실험
- 10: 사전 통지, 거절·종료권과 장래 적용이 포함된 정상 변경 예외 실험
- 11: 계속 사용·무응답·계속 거래로 동의를 간주하는 의미형 표현 실험

처음에는 위험 신호가 비교적 분명한 01번 문서를 권장합니다.
FinContract AI의 결과는 법률 판단이 아닌 검토 보조 결과입니다.
