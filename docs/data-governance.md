# 데이터 거버넌스

## 두 데이터 흐름의 분리

### 사용자 문서

- 목적: 해당 사용자 요청의 분석
- 저장: 암호화 파일 저장소와 PostgreSQL 메타데이터
- 외부 전송: PII 마스킹 검증 후 필요한 최소 조항만 허용
- 금지: ChromaDB 적재, 재학습, 다른 사용자 검색 코퍼스 재사용
- 삭제: TTL 및 사용자 DELETE 요청에 따라 처리

### 공개 리서치 코퍼스

- 목적: 법적 근거와 유사 사례 검색
- 저장: 원본·manifest와 ChromaDB 검색 인덱스
- 필수 항목: 출처, 권위 기관, 기준일, hash, 라이선스, 재배포 가능 여부
- 적재 조건: manifest schema 검증과 중복 제거 통과

## 통계 사용

641건과 16건은 현재 검증되지 않은 후보 규모입니다. `research_manifest.json`이 원본 수, 중복 제거 수, 채택 수와 제외 수를 증명하기 전에는 UI, README 또는 공모전 자료에 확정 통계로 표시하지 않습니다.

## 로그 정책

- API 키, 사용자 원문, 마스킹 매핑과 전체 LLM 응답을 기록하지 않습니다.
- 감사 로그에는 식별자, 상태 전이, 규칙·prompt·index 버전과 삭제 이벤트만 남깁니다.
