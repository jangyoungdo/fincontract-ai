# 법률 판단 경계

## 제공하는 것

- 불공정 가능성이 있는 조항의 위험 신호
- 탐지된 문구와 문서 내 위치
- 관련 법령·공식 지침·심결·판례·분쟁조정 사례 후보
- 위험 설명, 반대 사정과 추가 검토 질문
- 협상·검토용 개선 문안 예시

## 제공하지 않는 것

- 위법·적법 또는 약관 무효의 확정
- 법률적으로 안전하다는 보증
- 승소 가능성이나 처분 결과 예측
- 변호사 또는 법률 전문가의 자문 대체

## 적용 관계

문서가 다수 상대방을 위해 미리 마련된 약관인지, 개별 협상된 계약인지 불명확하면 `applicability=unknown`으로 표시합니다. 약관법 적용을 자동 확정하지 않습니다.

법적 근거는 약관법 제6조의 일반원칙과 제7조부터 제14조까지의 유형별 기준을 구분하고, 제17조는 사용금지의 연결 근거로 관리합니다. 모든 법령 레코드는 시행일, 출처와 manifest 버전을 가져야 합니다.
