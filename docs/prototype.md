# 프로토타입 001: 오프라인 에이전트 파이프라인

## 완성 범위

조항 텍스트 입력부터 개인정보 마스킹, 세 가지 규칙 선별, mock 분석 에이전트, 결과 검증과 사람의 승인까지 하나의 로컬 화면에서 실행합니다.

기본값은 네트워크를 전혀 사용하지 않는 `mock`입니다. mock은 규칙 결과에서 결정론적으로 설명을 조립해 전체 파이프라인과 UI를 검증하기 위한 것이며 실제 Claude 품질을 나타내지 않습니다.

## 실행

저장소 루트에서 실행합니다.

```bash
python3 backend/app/prototype/server.py
```

브라우저에서 `http://127.0.0.1:8080`을 엽니다. 화면은 단일 운영 분석만 실행합니다.

## 운영 모드와 평가 기준선

- 운영: PII 마스킹 → 19개 규칙 → 로컬 의미 후보 → 선택적 OpenAI 문맥 후보 → 근거·설명 보강 → 사람 검토
- 내부 평가: `rules-only` 기준선은 비공개 평가 CLI에서만 실행

이전 A/D 요청 값은 호환 입력으로만 처리하며 운영 동작을 선택하지 않습니다.

## 안전 경계

- 입력 원문은 저장하지 않고 해시와 마스킹된 텍스트만 인메모리에 유지합니다.
- 서버를 종료하면 분석과 리뷰가 모두 사라집니다.
- 검증된 RAG 코퍼스가 없으므로 법적 근거는 `candidate_unverified`로 표시합니다.
- API 키를 읽거나 외부 모델에 연결하지 않습니다.
- PII 탐지는 공통 식별자와 라벨형 이름·주소를 지원하고 OCR 결과에도 동일하게 적용됩니다. 다만 실제 OCR 오인식의 비정형 표기는 한국어·숫자·표·회전 회귀셋으로 추가 검증해야 합니다.
- 결과는 위험 신호이며 위법·적법 판단이 아닙니다.

## 프로토타입 이후 게이트

실제 Claude provider는 다음 조건을 모두 충족한 뒤 별도 실험으로 추가합니다.

1. 검증된 공개 코퍼스와 evidence ID 기반 retriever
2. PII 회귀셋과 outbound payload 잔존 PII 0건
3. 명시적인 live 실행 플래그와 키·모델 설정의 fail-closed 검사
4. provider 응답 스키마 및 인용 검증
5. mock과 live 결과를 분리하는 실험 저장소
